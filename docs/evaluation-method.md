# 서울 예보 신뢰도 평가 기준
상태: 기본 평가 기준 합의, 자료 시각 검증 진행 중. 2026-11-02 KST.

## 핵심 목적
기상청 예보가 실제로 얼마나 빗나갔는지, 어떤 조건에서 어느 정도 믿을 수 있는지 설명한다.
정확했던 사례와 부정확했던 사례를 함께 공개한다.

## 첫 버전
- 서울 대표 격자 (60,127), 대표 지점 성적이며 서울 전체 평균 아님.
- 정확히 24시간 전 발표한 예보와 같은 대상 시각의 실황 비교.
- 기온: 평균 절대오차, 편향, ±1℃ 및 ±2℃ 이내 비율, 표본 수와 자료 기간.
- 강수: 실황 시간 구간 정의 검증 후 평가. 예보했는데 안 온 경우/놓친 비 구분.
- 강수확률: 구간별 실제 강수 빈도 및 표본 수. 확률을 단일 사건의 정답 여부와 혼동하지 않음.
- 종합 신뢰도 점수로 임의 합산하지 않음. 누락은 제외하고 누락 수 공개.
- 첫 검증 구간은 고정 과거 기간임을 표시. 실제 확보 전 최근 30일로 표시하지 않음.

## 시간 관련 두 개의 독립된 문제
1. 자료 시각 정합성: 실황 CSV와 API가 같은 측정/집계 시각을 의미하는지 확인.
   현재 두 사례의 CSV 기온이 API +50분과 일치. 원인 미확정.
   이 차이를 예보의 시간 오차로 보고하지 않음. 자동 보정 금지.
2. 예보의 시간 오차: 예보한 기온 변화 또는 강수 사건이 실제로 얼마나 일찍/늦게 발생했는가.
   초기 구현에서 제외. 뚜렷한 변화 흐름의 시간 단위 분석만 후속 검토.

## 후속 검토 아이디어 (초기 구현 범위 아님)
- 원래 예보 시각의 기온 오차/강수 성적을 기본 성적으로 유지한다.
- 시간 이동 후 잘 맞는 결과는 보조 진단이며 기본 적중률을 올리는 데 쓰지 않는다.
- 임의 기온 하나의 값 일치만으로 시간 오차를 결정하지 않는다.
  기온은 같은 발표본의 상승/하강 추세와 극값 등을 포함한 연속 시계열로 평가한다.
- 분석 창과 방법은 추후 별도 검증 전에는 확정하지 않는다.
- 일정한 기온, 여러 후보가 동률, 변화 자체가 없음, 자료 누락, 경계에 걸린 사건은 판단 불가.
- 강수는 동일 정의의 시작/종료 시각 사건을 대응. 대응할 비가 없으면 시작 시각 오차를 계산하지 않는다.
- 부호: 실제 발생이 예보보다 늦으면 +, 빨랐으면 -.
- 현재 원본 예보가 시간 단위이면 분 단위 정확도로 예보 시간 오차를 주장하지 않는다.
  10분 실황이 있어도 예보 해상도의 한계를 명시한다.
- 여러 사례의 표본 수, 계산 가능 비율, 중앙 시간 차이, 범위 및 기본 오차를 함께 제시한다.
- 분석 방법과 식별 가능 기준은 자료 검증/테스트 후 확정. 현재 제품 화면에 표시하지 않는다.

## 계획 확정 시계
예측 잔여시간별 실제 성적을 토대로 사용자의 판단을 돕는다.
24시간 전 자료만으로 완성 불가. 같은 대상 시각의 48/24/12/6시간 전 예보 등 필요.
충분한 표본 전에는 확정 가능/안전 단정 금지. 현재 미구현.

## 다음 구현
서울 실황 시각 기준 확립 → 한 달 기본 성적 → 예측 잔여시간별 자료 확보 → 계획 확정 시계.
기온의 분 단위 시간 오차는 초기 범위에서 제외한다. 공식 시각 정의를 확인하고
평균 오차·편향·±1℃/±2℃ 이내 비율을 기본 지표로 사용한다.
14시 예보를 임의로 14~15시 구간으로 해석하거나 가장 가까운 값을 선택하지 않는다.

## 시간 차이 허용 정책 — 2026-11-02 최신 사용자 합의
서비스 자체의 보조 판정 기준이며 기상청 공식 정확도 기준 또는 과학적으로 검증된 허용 범위가 아님.
- 절대 시간 차이 1시간 이하: 허용 범위.
- 1시간 초과~2시간 미만: 경계.
- 2시간 이상: 주의.
실황 CSV/API의 50분 차이는 개발 전체의 선행 차단 사유로 삼지 않는다.
API 자료를 독립 출처로 수집하고 요청 발표시각/대상시각/출처를 보존한다.
이 정책은 서로 다른 자료의 시각 의미가 같다는 검증을 대신하지 않는다.
기온 기본 오차는 원래 대상 시각 기준으로 유지. ±1시간 안에서 맞는 온도를 골라
기본 적중률을 높이지 않는다. 기온 오차와 시간 차이 판정은 별개.
식별 가능한 변화 시점이 없으면 시간 차이 수치를 만들지 않는다.
강수는 기온에 대한 이 정책만으로 누적구간 검증을 생략하지 않는다.
판정 기능은 아직 미구현; 초기 제품의 주 작업은 서울 한 달 수집/기온 성적/화면 반영.
